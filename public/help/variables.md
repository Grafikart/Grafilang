# Variables

Les variables permettent de stocker une valeur pour la réutiliser plus tard dans l'algorithme.

## Syntaxe

```txt
VAR NOM = valeur
```

Pour modifier une variable déjà créée :

```txt
NOM = nouvelle_valeur
```

## Valeurs disponibles

- nombres, par exemple `3` ou `12.5`
- chaînes de caractères, par exemple `"Bonjour"`
- booléens, avec `VRAI` et `FAUX`

## Opérateurs courants

- `+` additionne des nombres ou concatène des chaînes
- `-`, `*`, `/` travaillent sur des nombres

## Exemples

```txt
VAR A = 3 + 2
AFFICHER A
```

```txt
VAR NOM = "Ada"
NOM = NOM + " Lovelace"
AFFICHER NOM
```

```txt
VAR NOTE = arrondir(12.7)
AFFICHER NOTE
```
